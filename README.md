# HMPS SI UIN IB - Kabinet Ekagrata

Website **Himpunan Mahasiswa Program Studi Sistem Informasi (HMPS SI) UIN Imam Bonjol Padang** yang dikembangkan sebagai media informasi dan pengenalan organisasi kepada mahasiswa.

Website ini mengusung identitas **Kabinet Ekagrata** dengan tagline:

> **"Initializing Our Future With Kabinet Ekagrata"**

## Tentang Website

Website HMPS SI dibuat sebagai media digital untuk menyampaikan informasi mengenai organisasi, kegiatan, profil, serta wadah bagi mahasiswa untuk menyampaikan aspirasi dan pengaduan.

Website dirancang dengan tampilan yang sederhana, modern, responsif, dan mudah digunakan pada berbagai perangkat.

## Fitur

### Home

Halaman utama yang menjadi landing page website HMPS SI. Halaman ini memberikan pengenalan singkat mengenai organisasi serta navigasi menuju berbagai informasi yang tersedia.

### Profil

Berisi informasi mengenai HMPS SI dan identitas organisasi serta kepengurusan.

### Info

Menyediakan informasi mengenai kegiatan dan berbagai informasi terbaru yang berkaitan dengan HMPS SI.

### Pengaduan

Menyediakan formulir bagi mahasiswa untuk menyampaikan aspirasi, masukan, maupun pengaduan kepada HMPS SI.

Pengguna dapat mengisi informasi yang diperlukan dan memiliki opsi untuk menyampaikan pengaduan secara anonim.

## Teknologi

Website ini dikembangkan menggunakan:

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
- Swiper.js
